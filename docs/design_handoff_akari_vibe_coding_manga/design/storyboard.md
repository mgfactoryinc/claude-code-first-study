## 見開き 1 ：プロローグ ── もう限界かも
ナレーション：都内のオフィス、深夜0時。書類の山に埋もれる、あかり30歳。
- 左：会社のデスク。書類の山とモニタに囲まれ、ため息をつくあかり。「はぁ〜〜…また残業…」
- 右：場面転換。バーのカウンターの中で、ボトルからグラスに注ぐバーテンダー姿のあかり。「夜はバーで副業…」

## 見開き 2 ：夜のバーカウンターで
ナレーション：副業で週に三日、このバーで接客をしています。
- 左：グラスを磨くあかり。「いらっしゃいませ…あら今夜はちょっと閑候？」
- 右：カウンターの客席に、スマホを見ているおじさん。カウンター越しに見るあかり。「（あの常連さん…スマホに何を話してるんだろ？）」

## 見開き 3 ：バイブコーディングおじさん、あらわる
ナレーション：気になって、接客中に思わず聞いてしまった。
- 左：おじさんがスマホの画面をこちらに向ける。あかり「あの、それって何ですか？」／おじさん「「バイブコーディング」ですよ〜」
- 右：人差し指を立てて説明するおじさん。「AIに話しかけてコード書いてもらうんスよ〜」／あかり、目を輝かせて「バイブ…？ｺｰﾃﾞｨﾝｸﾞ…？」（キラキラ）

## 見開き 4 ：覚えて① Visual Studio Code
ナレーション：まず、道具の名前を教えてもらいます。
- 左：おじさんがコード画面の出たスマホを見せる。「これが「Visual Studio Code」通称 VSCode！」／補足「無料。Windows も Mac も入るプログラミング用のメモ帳、みたいなヤツです」
- 右：あかりの顔アップ。VSCode をデフォルメしたマスコットが浮かんでいる。「これがエディタ…覚えた！」

## 見開き 5 ：覚えて② Claude と Code
ナレーション：そして、この物語の相棒たちの名前。
- 左：カウンターの上に光るカニのマスコット。おじさん「相棒はこの子、「Claude（クロード）」AIの名前ね」
- 右：カニに手を差し出すあかり（ハートが舞う）「クロードくん…♡よろしくねっ」／サムズアップするおじさん「そして「Code（コード）」がお願い窓口！」

## 見開き 6 ：覚えて③ .md と CLAUDE.md
ナレーション：最後に、AIへの「お手紙」の話。
- 左：空白の書類アイコンが宙に浮かぶ。おじさん「「.md」って拡張子ね。ただのメモ帳と思って」
- 右：フォルダアイコンからカニが顔を出す。おじさんがあかりに封筒を手渡す。「作業フォルダには毎回「CLAUDE.md」を置くのがオススメ〜」／封筒に添えて「AIくんへのお願いレターです📮」

## 見開き 7 ：帰宅、いざインストール
ナレーション：その夜、家に帰ってさっそく…！
- 左：自宅の机、デスクライトの下でノートPCに向かい、こぶしを握るあかり。「よ〜し、やるぞ〜〜っ！」
- 右：インストーラの進捗バーが伸びるノートPCの画面。手順「① VSCode をダウンロード ② インストール ③ 日本語化パックを入れる」

## 見開き 8 ：拡張機能と、作業フォルダ
ナレーション：次にやるのは、たった2つ。
- 左：拡張機能をパズルのピースで表した画面を操作するあかり。手順「④ 拡張機能で「Claude Code for VS Code」をインストール」
- 右：フォルダとカニのアイコンを指差すあかり。手順「⑤ エクスプローラーで作業フォルダを作成 ⑥ CLAUDE.md を新規作成」／「準備できた…！」

## 見開き 9 ：はじめまして、クロード
ナレーション：ドキドキしながら、Code に話しかけてみた。
- 左：緊張した表情でキーボードを打つあかり。「は、はじめまして…」／PC 画面に返事「Claude：はじめまして、あかりさん 🦀」
- 右：両手を頬に当てて感涙するあかり。傍らにカニ。「返事きた〜〜っ！！(嬉泣)」

## 見開き 10 ：資料を作ってみる（.md → HTML → SVG）
ナレーション：勉強会の資料を、Claude と一緒に作ってみることに。
- 左：書類アイコンがブラウザ画面に変換されていく図。あかり「まず「.md」で中身を書いて…」／「「HTMLで見やすくして」ってお願い！」
- 右：図表の並んだノートPC画面を掲げるあかり。「図は「SVG」で作ってもらった〜かわいい♡」

ナレーション：作ったポートフォリオを手に、面接へ。
