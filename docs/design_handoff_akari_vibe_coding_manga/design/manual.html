『あかりさんの バイブコーディング転職記』付録

漫画であかりさんがやっていたことを、実際の画面でたどります。
ゴールは「Claude に話しかけられる状態」になること。だいたい 15〜20分。
プログラミングの知識はいりません。書くのは日本語だけです。

もくじ

準備編 ── 道具をそろえる

  1. VSCode を入れる
  2. 画面を日本語にする
  3. Claude Code を入れる

実践編 ── 話しかけるまで

  1. 作業フォルダを作って開く
  2. 「制限モード」を解除する
  3. 画面の見かたを覚える
  4. CLAUDE.md を作る
  5. 話しかけてみる

おまけ

  1. ショートカット早見表
  2. つまずいたら
  3. 用語ミニ辞典

1VSCode を入れる

所要 5分 ／ 漫画 第4話・第7話

Visual Studio Code（通称 VSCode）は、無料の「プログラミング用のメモ帳」です。Windows でも Mac でも使えます。まずはこれを入れます。

  1. code.visualstudio.com を開く
  2. 大きな Download ボタンを押す
    • 自分のパソコン（Windows / Mac）に合ったものが自動で選ばれます
  3. ダウンロードしたファイルを開いて、インストールする
    • 途中の選択肢は、基本そのまま「次へ」で進んで大丈夫です
Windows の人へ

インストール時に「エクスプローラーのコンテキストメニューに『Code で開く』アクションを追加する」という項目があれば、チェックを入れておくと STEP 4 がラクになります。

📖 漫画で見る（第4話・第7話）

2画面を日本語にする

所要 2分 ／ 漫画 第7話

入れたばかりの VSCode は英語です。日本語化しておくと、この先がぐっとラクになります。

  1. 左端のアイコンが縦に並んだ帯（アクティビティバー）から、四角が4つ組み合わさったアイコン（拡張機能）をクリック
  2. 検索欄に Japanese と入力
  3. Japanese Language Pack for Visual Studio Code を選んで Install
    • 発行元が Microsoft のものを選んでください
  4. 右下に出る Change Language and Restart を押して再起動

再起動すると、メニューが日本語になります。この先の説明は、すべて日本語表示を前提にしています。

3Claude Code を入れる

所要 2分 ／ 漫画 第5話・第8話

ここが本番の道具です。Claude が AI 本体の名前、Code がそれにお願いするための窓口。VSCode の中にこの窓口を追加します。

  1. もう一度、左端の 拡張機能 アイコンをクリック
  2. 検索欄に Claude Code と入力
  3. 見つかった拡張機能を インストール
アカウントについて

初回は Claude のアカウントでサインインを求められます。画面の案内にしたがって進めてください。会社のアカウントを使う場合は、事前に管理者に確認を。

4作業フォルダを作って開く

所要 2分 ／ 漫画 第8話

AI には「どのフォルダで作業するか」を教えてあげる必要があります。まず、作業フォルダを1つ用意しましょう。

  1. デスクトップなど、分かりやすい場所に新しいフォルダを作る
    • 名前は何でもOK。ここでは 勉強会 にしています
  2. そのフォルダを右クリック
  3. メニューの中から Code で開く を選ぶ
メニューに出てこないときは

Windows 11 では その他のオプションを確認 の中に隠れていることがあります。それでも無い場合は、VSCode を先に起動して ファイル → フォルダーを開く から選んでもまったく同じです。

5「制限モード」を解除する

所要 30秒 ／ ここでつまずく人がいちばん多い

フォルダを開いた直後、VSCode は安全のため「制限モード」になっています。このままだと拡張機能が十分に動かず、AI にお願いしても反応しません。

画面の上に 制限モードは、安全なコード参照のためのものです。… という帯が出ていたら、管理 を押してください。次の画面になります。

信頼していいのは、自分で作ったフォルダだけ

「信頼する」は、そのフォルダの中身を VSCode に実行させてよい、という意味です。自分で作ったフォルダや、出どころが確かなフォルダだけにしてください。ネットで拾ってきた知らないフォルダは、そのまま信頼しないこと。

6画面の見かたを覚える

所要 3分 ／ 覚えるのは5か所だけ

ここが VSCode の基本画面です。ボタンがたくさんありますが、最初に覚えるのは5か所だけで足ります。

チャットが見当たらないときは

Ctrl＋Alt＋I を押すとチャットが開きます（Mac は ⌘＋Option＋I）。

7CLAUDE.md を作る

所要 3分 ／ 漫画 第6話

CLAUDE.md は、AI への「お願いレター」です。作業フォルダに置いておくと、Claude が毎回これを読んでから動いてくれます。「日本語で答えて」「初心者なので噛みくだいて」といったことを、毎回書かなくてよくなります。

.md は「マークダウン」という、ただの文字だけのメモ帳ファイルの拡張子です。むずかしいものではありません。

  1. エクスプローラー（左側）の何もないところを右クリック
  2. 新しいファイル... を選ぶ
  3. ファイル名に CLAUDE.md と入力して Enter

ファイルが開いたら、中に次のような内容を書いて保存（Ctrl＋S）します。そのままコピーして使ってかまいません。

# このフォルダについて

## わたしについて
- プログラミングは初心者です。専門用語は、かみくだいて説明してください。
- 返事はかならず日本語でお願いします。

## このフォルダでやりたいこと
- （例）勉強会で使う資料を作る

## お願いごと
- ファイルを変更する前に、何をするか一言だけ教えてください。
- うまくいかないときは、勝手に進めずに質問してください。
- わたしが指示していないことは、やらないでください。
実物が見たいときは

この教材のリポジトリのルートに置いてある CLAUDE.md が、実際に使われている CLAUDE.md です。説明用に書いたサンプルではありません。 まるごとコピーして、自分の作業フォルダ用に書き換えてかまいません。

中身は自由です

決まった書き方はありません。新しく入った人に渡す業務メモのつもりで、自分の言葉で書けば大丈夫です。あとからいくらでも書き足せます。

8話しかけてみる

所要 1分 ／ 漫画 第9話・第10話

準備はこれで終わりです。あとは日本語で話しかけるだけ。

  1. Ctrl＋Alt＋I でチャットを開く
  2. 入力欄に、やってほしいことを日本語で書く
  3. Enter で送信

最初の一言に迷ったら、このあたりから。

やりたいこと話しかけかたの例
あいさつ・動作確認 はじめまして。このフォルダには何が入っていますか？
資料のたたき台を作る 勉強会の資料を作りたいです。まず outline.md に見出しだけ書いてください。
見やすい形にしてもらう outline.md の内容を、HTML にして見やすくしてください。
図を作ってもらう この流れを図にしてください。SVG でお願いします。
分からないことを聞く いま何をしたのか、初心者にも分かるように説明してください。
コツは「短く、ひとつずつ」

いちどに全部お願いするより、ひとつ頼んで、結果を見て、次を頼むほうがうまくいきます。違うと思ったら「そうじゃなくて、こうしてほしい」と伝えれば直してくれます。会話なので、やりなおしは何度でもできます。

◎つまずいたら

よくある詰まりどころ

チャットにお願いしても、何も起きない／反応がない

まず 制限モード を疑ってください。画面の左下に 制限モード と表示されていたら、まだ解除されていません。STEP 5 に戻って「信頼する」を押してください。

右クリックしても「Code で開く」が出てこない

Windows 11 なら その他のオプションを確認 の中を見てください。それでも無ければ、VSCode を起動して ファイル → フォルダーを開く から選べば同じことができます。

チャットのパネルが消えてしまった

Ctrl＋Alt＋I（Mac は ⌘＋Option＋I）で開き直せます。

AI が英語で返事をしてくる

CLAUDE.md に「返事はかならず日本語でお願いします」と書いて保存してください。その場で直したいときは、チャットに「日本語でお願いします」と送るだけでも切り替わります。

意図しないファイルが書き換えられた／元に戻したい

ファイルを開いて Ctrl＋Z で戻せます。大事なフォルダでいきなり試さないのがいちばんの予防です。まずは空のフォルダで練習してください。

そもそも自分が何をしているのか分からなくなった

チャットに「いま何をしたのか、初心者にも分かるように説明してください」と送ってください。AI は、自分がやったことを説明するのも得意です。恥ずかしがらずに何度でも聞いてかまいません。
