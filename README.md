# あかりさんの バイブコーディング転職記

**プログラミングをやったことがない人が、AI に話しかけてコードを書いてもらえるようになるまで。**
それを 12 話の漫画と、実際の画面つきマニュアルにした教材です。

エムジーファクトリー株式会社の AI エージェント勉強会（5分プレゼン）のために作りました。
社内・社外を問わず、勉強会の教材としてそのまま使えます。

---

## まず、見てみる

| | |
|---|---|
| 📖 **漫画を読む** | <https://mgfactoryinc.github.io/claude-code-first-study/> |
| 📘 **マニュアルを見る** | <https://mgfactoryinc.github.io/claude-code-first-study/manual.html> |

漫画は **→ キー**で次のページ、**← キー**で戻ります（画面の右半分をクリックでも進みます）。

### ダウンロードして見る場合（Git を知らなくて大丈夫です）

1. このページの上のほうにある緑色の **`< > Code`** ボタンを押す
2. **Download ZIP** を選ぶ
3. ダウンロードした ZIP を解凍する
4. `docs` フォルダの中の **`index.html`** をダブルクリック

インターネットにつながっていれば、それだけで読めます。

## 勉強会で使うときのヒント

- 全 14 見開き。1 見開き 25 秒くらいのペースで、ちょうど **5 分**です
- **F11** で全画面にすると、投影がきれいです
- マニュアルは **Ctrl+P** で印刷できます（目次やボタンは自動で消えて、折りたたみも開いた状態で出ます）。A4 で配布資料になります
- セリフを自分たちの会社向けに書き換えたいときは `docs/script.js` を編集してください
